# Decoders

Downstream evaluation scripts for pretrained embeddings.

- `predict_mcmaze_velocity.py`: frozen MC Maze velocity decoders.
- `predict_mcmaze_velocity_finetune.py`: MC Maze decoder with embedder fine-tuning.
- `predict_mcmaze_velocity_raw.py`: raw-input MC Maze velocity baseline.
- `predict_physionet_condition.py`: frozen PhysioNet condition decoder.
- `predict_physionet_condition_finetune.py`: PhysioNet decoder with optional embedder fine-tuning.
- `evaluate_mcmaze_test_velocity.py`: MC Maze test-set prediction export.
