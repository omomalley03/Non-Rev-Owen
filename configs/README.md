# Configs

Shell configuration files for local runs.

- `mcmaze_config.sh`: MC Maze pretraining defaults for `main.py`.
- `physionetmi_config.sh`: PhysioNetMI pretraining defaults for `main_synth.py`.
- `faced_config.sh`: FACED defaults for `main_synth.py`.


Typical usage:

```bash
source configs/mcmaze_config.sh
python main.py
```
